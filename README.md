# 🎵 90s Hindi Radio

![90s Hindi Radio](https://img.shields.io/badge/Status-Live-success)
![Platform](https://img.shields.io/badge/Platform-Web-blue)
![License](https://img.shields.io/badge/License-MIT-green)

A beautiful, responsive, and completely free web-based music player dedicated to the golden era of 90s Bollywood music. Stream hours of classic hits without any ads, interruptions, or YouTube API dependencies!

## ✨ Features

- **Real Audio Streaming**: Directly streams high-quality MP3 mixes from the Internet Archive (`archive.org`). No YouTube embeds or iframe issues.
- **Curated Playlists**: Includes 7 hand-picked jukeboxes featuring legends like Kumar Sanu, Alka Yagnik, Udit Narayan, and more.
- **Stunning UI/UX**:
  - Glassmorphism design with a premium dark mode aesthetic.
  - Animated spinning vinyl record with a dynamic tonearm.
  - 16-bar responsive audio equalizer animation.
  - Interactive background particle effects.
- **Full Player Controls**: Play/Pause, Next/Previous, Shuffle, Repeat, Timeline Scrubbing, and Volume Control.
- **Responsive Design**: Works flawlessly on desktops, tablets, and mobile devices.

## 🛠️ Built With

- **HTML5** & **CSS3**: Pure vanilla web technologies for a lightweight, lightning-fast experience.
- **JavaScript (ES6)**: Custom logic for native HTML5 `<audio>` element control, state management, and UI updates.
- **Internet Archive API**: Free and legal public domain / open source audio hosting.

## 🚀 Getting Started

### Local Development
Since this is a static site with no build process, running it locally is incredibly simple:

1. Clone the repository:
   ```bash
   git clone https://github.com/beakash/Music-player.git
   ```
2. Open `index.html` in your favorite web browser.
3. Enjoy the music!

### Deployment
This project is configured for instant deployment on [Render](https://render.com) using the included `render.yaml` file.

1. Go to your Render Dashboard and click **New > Static Site**.
2. Connect your GitHub repository.
3. Render will automatically detect the settings from `render.yaml`.
4. Click **Create Static Site**.
